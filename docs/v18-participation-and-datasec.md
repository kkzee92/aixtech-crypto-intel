# Version 0.18 participation guards and data-security plane

`crypto-intel v18` is a fourteenth pass. It can only shrink paper size. It does
not open a socket, store a secret, or place an order.

| Class | Guard | Effect |
|---|---|---|
| Major | Close-location haircut | A long that closes in the bottom quartile of the bar halves size |
| Large-cap alt | Climax-volume haircut | Last volume above 3x the prior median halves size |
| Stablecoin | Peg-band straddle watch | A bar through both sides of an 8 bp band is a watch. Size stays zero |
| DeFi | Failed-break haircut | A high that breaks the prior range and closes back inside halves size |
| Meme | One-bar climax veto | A range above 12 percent with 3x volume zeroes size |
| L2 | Lag haircut | A negative three-bar return halves size |
| RWA | Identical-print veto | Three unchanged closes zero size |
| Perpetual | Funding-flip haircut | A funding sign change of at least 3 bp halves size |

`crypto-intel console` publishes an offline digest. `crypto-intel datasec`
describes the data-security plane. `screen_record` refuses secret, wallet, and
personal-data fields before a research packet can leave. Neither path can
place an order or enable live trading.

This is a research design, not a certification and not financial advice.
