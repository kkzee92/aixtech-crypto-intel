# v0.3 Enhancements

Research-only improvements to the paper trading information system.

## Strategy layer

- Stronger volume and relative-volume filters on breakout and major trend rules.
- Explicit volatility awareness in signal reasons.
- Chase and extension filters tightened on meme and RWA paths.
- Regime overlay remains mandatory; stress still forces flat.

## Risk layer

- Optional ATR-based size scaling when recent bar range is elevated.
- Class caps, confidence floors, kill switch, and drawdown halt unchanged.

## Security / data controls

- Expanded secret patterns (hex private-key shape, AWS-style keys, mnemonic keywords).
- Audit events now stamp UTC ISO timestamps inside the hashed detail.
- New integrity_digest helper for source attestation.
- Redaction and paper-only guards preserved and strengthened.

## Still out of scope

- Live order routing, exchange trade keys, withdrawal paths.
- Any claim of future returns. Scores describe synthetic fixtures only.

Human review required before any production use.
