# Version 0.20 inventory-age guards and disclosure boundary

`crypto-intel v20` is a sixteenth pass. It can only shrink paper size. It does
not open a socket, store key material, or place an order.

| Class | Guard | Effect |
|---|---|---|
| Major | Participation drought | Last three volumes below 60 percent of the median halves size |
| Large-cap alt | Failed follow-through | Close below the prior three-bar midpoint halves size |
| Stablecoin | Peg persistence | Two closes at least 20 bp off peg are a watch. Size stays zero |
| DeFi | Jump without range | A 4 percent move inside a 1 percent bar halves size |
| Meme | Climax fade | A burst that closes down on falling volume zeroes size |
| L2 | Stall | Three flat closes and collapsing volume halves size |
| RWA | Smoothness break | Last range above three times the median halves size |
| Perpetual | Funding flip | A sign change in the last two funding prints zeroes size |

`crypto-intel dispatch` publishes an offline digest. `crypto-intel boundary`
describes the disclosure-boundary plane. Allowed zones are
`research_internal`, `audit`, and `public_brief`. A public brief drops paper
size and is redacted. Trade, withdrawal, seed, private-key, and api-key tokens
are blocked. Crossing a zone cannot enable live trading.

This is a research control, not a MAS TRM, PDPA, SOC, NIST, or ISO certification.
